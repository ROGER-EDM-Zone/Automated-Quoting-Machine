Getting the quoting app running on your PC

Every step, in order, with what you should see after each one. Follow it top to bottom. Nothing here needs anyone technical.

Do it in one sitting if you can — about an hour. If you have to stop, stop at the end of a stage rather than partway through one.

5 minA · Outlook
10 minB · Microsoft sign-up
15 minC · Install on the PC
10 minD · Connect it
10 minE · First real RFQ
Before you start — one thing that costs money

Stage C asks for an Anthropic API key. That is what pays for reading drawings, and it is billed on usage — roughly a few pence per drawing. You put a card on the account and set a monthly cap.

You can skip it and come back. Without it everything works except reading drawings automatically: enquiries still arrive, and you can still type the details in and let it price them.

STAGE A

Set up the tag in Outlook

5 minutes

This is the switch that decides what the app looks at. Only emails you tag RFQ are ever read — everything else in the mailbox is invisible to it.

  1. Open the sales mailbox in Outlook

    Not your own inbox — sales@edmzone.co.uk. In the folder list down the left, click into the sales mailbox so you are looking at its messages.

    Why this matters

    Tags belong to a mailbox. If you make it while looking at your own inbox, it lands on your list and the app will never see it.

  2. Create the tag

    Right-click any email in that mailbox, then:

    Categorise → All Categories → New

    Type the name exactly:

    RFQ

    Three capital letters. No space after. Pick any colour you like — the colour makes no difference to the app, only to your eyes.

    Click OK, then OK again.

    Get this exactly right

    Rfq, rfq or RFQ  with a trailing space are all different tags as far as Microsoft is concerned. If it is wrong, nothing happens and nothing tells you — mail arrives, the app looks for RFQ, finds nothing, and stays quiet.

    The connection check in Stage D catches this and names it. But it is easier to get right now.

  3. Tag one real RFQ, ready for later

    Find a genuine RFQ that arrived recently — one with a drawing attached is ideal. Right-click it, Categorise, RFQ.

    That is your test message for Stage E. Leave it there.

    You should now see
    A coloured RFQ label on that email in the sales mailbox.
STAGE B

Give the app permission to read that mailbox

10 minutes

This is Microsoft's side. You are registering the app so it can ask for access, then signing in yourself to grant it. It is all on one website and you need nothing from anyone else.

  1. Open the Microsoft admin page

    Go to:

    https://entra.microsoft.com

    Sign in with your normal EDM Zone account. If it says you do not have access, you are not an administrator — stop here and tell me, there is a different route.

  2. Start a new registration

    Down the left-hand side:

    Applications → App registrations → + New registration

    Fill in the form:

    • Name: EDM Zone Quoting
    • Supported account types: the first option — Accounts in this organizational directory only
    • Redirect URI: leave completely blank

    Click Register.

  3. Copy the two ID numbers

    The page that appears has two long numbers near the top. Copy both into Notepad — you need them in Stage C.

    On the screenLooks like
    Application (client) IDa string of letters, numbers and dashes
    Directory (tenant) IDshould be 2a4247d5-e81d-4869-84f7-d84d64122c7b
    These two are safe

    Neither is a password. They identify the app but grant nothing on their own, so it is fine to email them or paste them to me.

  4. Turn on the sign-in method

    In the menu down the left of this app's page:

    Authentication → scroll to the bottom → Advanced settings

    Find Allow public client flows and switch it to Yes. Click Save at the top.

    The step everyone misses

    Skip this and Stage D fails with an unhelpful message about clients. If that happens, come back here — this is almost always why.

  5. Say what the app may do

    API permissions → + Add a permission → Microsoft Graph

    You are then asked to choose between two kinds. Choose Delegated permissions.

    In the search box that appears, type Mail.Read and tick it. Then clear the box, type Mail.ReadWrite and tick that too. Click Add permissions.

    You should now see
    Two rows in the list: Mail.Read and Mail.ReadWrite, both marked Delegated. There may be a third called User.Read that was already there — leave it.
    No "Grant admin consent" needed

    You may see that button. You do not need to press it. Delegated permissions are granted by you when you sign in during Stage D, and the app can only ever see what you can see.

STAGE C

Put the app on your PC

15 minutes

Mostly waiting for things to download. Do this on the PC that will be left on — the app only runs while that machine is awake.

  1. Install Python

    This is the engine the app runs on. Go to python.org/downloads and click the big yellow Download Python button.

    Run the file it downloads. On the very first screen of the installer:

    Tick this box before clicking Install

    Add python.exe to PATH — it is a small tick box at the bottom, and it is off by default. Without it the setup in step 4 will not find Python and will stop.

    Then click Install Now and wait.

    If Python is already on this PC

    Fine — the setup checks the version. It needs 3.11 or newer and will tell you if what is there is too old.

  2. Download the app

    Go to the project on GitHub:

    https://github.com/ROGER-EDM-Zone/Automated-Quoting-Machine

    Click the green Code button, then Download ZIP.

  3. Unblock it, then unzip it

    Find the ZIP in your Downloads. Before opening it, right-click it and choose Properties. At the bottom of that window, if there is an Unblock tick box, tick it and click OK.

    Why

    Windows marks everything downloaded from the internet as untrusted, and that mark spreads to every file inside the ZIP. Unblocking now saves a confusing failure later.

    Now right-click the ZIP → Extract All. Put it somewhere you will find again — C:\EDMZone\Quoting is a good choice. Avoid Desktop and OneDrive folders.

  4. Run the setup

    Open the folder you just extracted, go into install, and double-click:

    START-HERE-Setup.bat

    A black window opens and works through the steps, printing [ok] as each one passes. The longest part is installing the app's components — a few minutes on a first run.

    You should end with

    Setup finished in green, and a new EDM Zone Quoting shortcut on your Desktop.

    If it stops with a red message

    The message says what to fix. Sort that, then run the same file again — starting over is always safe, it picks up where it left off.

  5. Get an Anthropic key, for reading drawings

    Go to console.anthropic.com, create an account, and add a payment card under Billing. Set a monthly spend limit while you are there — start low, £20 is plenty to begin with.

    API keys → Create Key

    Copy the key it shows you. Like the client secret, it is shown once. It starts sk-ant-.

    This one is a password

    Do not email it, and do not paste it into this chat. It goes straight into the settings file in the next step.

STAGE D

Connect it to the mailbox

10 minutes

  1. Put your details in the settings file

    In the app folder, go into backend and find the file called .env — just a dot and "env", no name before it. Right-click it → Open with → Notepad.

    Fill in the three blanks from Stages B and C:

    AQM_GRAPH_TENANT_ID=paste the Directory (tenant) ID
AQM_GRAPH_CLIENT_ID=paste the Application (client) ID
AQM_ANTHROPIC_API_KEY=paste the sk-ant-... key

    No quote marks, no spaces around the =. Everything else in the file is already correct. Save and close.

    This file is now sensitive

    It holds a key that spends money and details that reach your mailbox. Do not email it, do not copy it into OneDrive or SharePoint, and do not paste its contents into a chat.

  2. Sign in

    Back in the install folder, double-click:

    Sign-in.bat

    It shows a web address and a short code. Open that address in your browser, type the code, and sign in as sales@edmzone.co.uk — or as yourself if you can open that mailbox from your own account.

    Microsoft will ask you to confirm the app may read your mail. Say yes. Then go back to the black window; it finishes on its own.

    You should see

    [ok] Signed in, then [ok] Reading: Sales - EDM Zone.

  3. Check the connection

    Double-click:

    Check-connection.bat

    This walks the whole connection and stops at the first thing wrong. It is read-only — it cannot change or send anything, so run it whenever you like.

    You want to see

    Green ticks all the way down, ending with the number of tagged messages waiting — which should include the one you tagged in Stage A.

    If anything is red

    Read it — it names the problem and the fix. If it does not make sense, send me the text and I will tell you what it means.

STAGE E

Start it, and watch a real RFQ come through

10 minutes

One thing to know before you look: it will not produce a price, and that is right. There are no rates in it yet and it has no defaults, so it refuses to quote rather than invent a figure. What you are testing here is whether it reads your drawings properly.

  1. Start the app

    Double-click EDM Zone Quoting on your Desktop.

    A black window opens and stays open — that is the app running. Your browser opens by itself at http://localhost:8000 after a few seconds.

    Leave the black window open

    Closing it stops the app. Minimise it instead. If you close it by accident, just double-click the Desktop shortcut again.

  2. Watch the RFQ arrive

    The app checks the mailbox every five minutes on its own. To see it now rather than waiting, click Check for new enquiries at the top of the queue.

    You should see

    The email you tagged in Stage A appearing as a row in the queue, with the customer, the subject and its drawings.

  3. Open it and look properly

    Click the subject to open it. This is the moment worth taking slowly — what the AI read off the drawing, what it was unsure of, and what it flagged.

    There will be no price, and that is correct

    You will see red blocking flags saying there is no rate for milling, or turning, or wire. That is the app working as designed, not a fault: it has no rates in it yet, and it has no default rate anywhere in it. It refuses to quote rather than guess a number nobody in your business chose.

    Nothing prices until you put your hourly rates in on the Rates screen. That is deliberately the next conversation, because it depends on the one question I still need answered — whether your £65/hour is what the customer pays or what an hour costs you.

    So what you are judging at this stage is only this: did it read the drawing correctly? Material, quantity, tolerance, dimensions, and what it says it was unsure about.

    Nothing can escape

    The app has no permission to send email. It can write a draft into Outlook; a person has to open it and press send. That is enforced by Microsoft, not by a setting I could get wrong.

  4. Tell me how it did

    Send me what it read versus what you would have said. That comparison is the whole point of getting this far — it tells us whether this saves you time or just gives you something new to check.

    Then we do the numbers: your rates, your allowance, your material prices.

If something goes wrong

Nothing here can break anything. The worst case is that it does not start, and you delete the folder and try again.

"Python was not found" or the setup stops at step 1

The Add python.exe to PATH box was not ticked. Re-run the Python installer, choose Modify, and tick it. Or uninstall Python and install again, ticking it this time.

A wall of red text about "execution policy" or "not digitally signed"

You ran Setup.ps1 directly. Run START-HERE-Setup.bat instead — it exists precisely to get round this.

Sign-in fails mentioning "unauthorized_client" or "public client"

Allow public client flows in Stage B step 4 is still off, or Save was not clicked. Go back and check.

The check is green but no emails appear

Almost always the tag. Check it is exactly RFQ, that it is on the sales mailbox rather than your own, and that at least one email actually carries it. The connection check lists every tag it can see in that mailbox — compare that list against what you expect.

The browser says it cannot reach localhost:8000

The app is not running. Check the black window is still open. If it closed with a message, send it to me.

Anything else

Send me the text from the black window — all of it, not a summary. These messages are written to say which of the several possible causes it is, and that detail is the useful part.
