Getting the quoting app running on your PC

Every step, in order, with what you should see after each one. Follow it top to bottom. Nothing here needs anyone technical.

Do it in one sitting if you can — about an hour. If you have to stop, stop at the end of a stage rather than partway through one.

20 minA · Install it
5 minB · Key for reading drawings
5 minC · Start it
—D · Drag emails in
This got much shorter

There is no Microsoft sign-up any more, no administrator, no permissions and no waiting on anybody. You drag RFQ emails out of Outlook and drop them on the app. The drawings come with them.

Connecting the mailbox so it collects them by itself is still there for later, in Connecting the app to sales@. It changes nothing about how the app works — only who does the fetching.

One thing costs money

Stage B asks for an Anthropic key. That is what pays for reading drawings — roughly a few pence each. You put a card on the account and set a monthly cap.

You can skip it and come back. Without it the app still takes emails in, still stores the drawings, and still prices anything you type in yourself. It just will not read the drawings for you, which is most of the point.

STAGE A

Put the app on your PC

20 minutes

Mostly waiting for downloads. Do this on the PC you will actually use — the app runs there and nowhere else.

  1. Install Python

    The engine the app runs on. Go to python.org/downloads and click the big yellow Download Python button, then run the file it gives you.

    Tick this box before clicking Install

    Add python.exe to PATH — bottom of the very first screen, off by default. Without it Stage A step 4 stops and cannot find Python.

  2. Download the app

    https://github.com/ROGER-EDM-Zone/Automated-Quoting-Machine

    Green Code button, then Download ZIP.

  3. Unblock it, then unzip it

    Find the ZIP in Downloads. Before opening it, right-click → Properties → tick Unblock if it is there → OK.

    Why

    Windows marks everything from the internet as untrusted and that mark spreads to every file inside. Unblocking now saves a confusing failure in a minute.

    Then right-click → Extract All. When it asks where, clear the box and type exactly:

    C:\EDMZone\Quoting
    Not the Desktop, even though that looks easiest

    At work your Desktop and Documents are almost certainly not on this PC at all — they are kept on the office server, and Windows just shows them as if they were local. The app cannot run from there: it needs to lock files while it works, and network folders do not allow that.

    You can check: open the folder, click in the address bar, and look at what it says. If it starts with two backslashes — \\EDM-DC\… — it is on the server. Move it to C:\EDMZone\Quoting and carry on. The setup checks this too, and stops with the same advice if it spots it.

  4. Run the setup

    Open the folder, go into install, and double-click:

    START-HERE-Setup.bat

    A black window works through the steps printing [ok] as each passes. Installing the components takes a few minutes the first time.

    You should end with

    Setup finished in green, and an EDM Zone Quoting shortcut on your Desktop.

    If it stops in red

    The message says what to fix. Sort it and run the same file again — starting over is always safe.

STAGE B

Get a key for reading drawings

5 minutes

  1. Create the account and set a spend cap

    Go to console.anthropic.com, sign up, and add a card under Billing. Set a monthly limit while you are there — £20 is plenty to start.

  2. Make a key

    API keys → Create Key

    Copy what it shows you. It starts sk-ant- and is shown once.

  3. Put it in the settings file

    In the app folder go into backend and find .env — just a dot and "env". Right-click → Open with → Notepad. Find this line and paste the key after the equals sign: 

    AQM_ANTHROPIC_API_KEY=paste it here

    No quote marks, no spaces. Save and close.

    That file is now a password

    Do not email it, do not put it in OneDrive, and do not paste its contents into a chat window.

STAGE C

Start it

5 minutes

  1. Double-click the Desktop shortcut

    EDM Zone Quoting. A black window opens and stays open — that is the app running. Your browser opens by itself at http://localhost:8000 after a few seconds.

    Leave the black window open

    Closing it stops the app. Minimise it instead.

    You should see

    Three drop zones across the top — Wire EDM only, Spark erosion only, Full supply — and the working lists beneath them, all empty.

  2. Check your rates went in

    Click Rates in the menu. Every process should read £65.00/h. Click Rules and you should see the allowance: 4mm on the section, 10mm on the length.

    Both are yours and both are editable here — changing a rate is you typing a number, no developer and no reinstall.

STAGE D

Drag your first RFQ in

the actual work

This is the bit you will do every day. Everything above happens once.

  1. Pick the right zone

    In Outlook, find an RFQ. Drag it straight out of the message list and drop it on one of the three:

    ZoneUse it when
    Wire EDM onlyFree issue, wire work. Nothing else gets added to the routing
    Spark erosion onlyFree issue, spark work. Same
    Full supplyYou are buying the material. Operations worked out from the drawing

    Several at once is fine. .msg straight from Outlook works; so does .eml.

    You should see

    A line saying what came in and how many drawings, then the enquiry appearing in the lists below.

    Dropped it on the wrong one?

    Not a problem — open the enquiry and change the job type there. And dragging the same email in again never overwrites a correction you have made.

  2. Open it and read what it made of the drawing

    Click the subject. You get what it read with a confidence figure against each field, what it honestly could not read, the operations it proposes, and the cost build-up.

    Three things are worth knowing how to read at a glance:

    • A time in amber dashed is one the AI estimated from a past job — check it. Plain text is calculated.
    • not read means it could not read that field and is saying so rather than guessing.
    • A material price in amber marked estimate is my ballpark figure, not one read off a supplier's page.

  3. Tell it what it could not know

    At the bottom is Notes. Type in plain English — "we already have the electrode for this, drop 15 minutes of setup", or "this one is awkward, add 15%" — and it reprices.

    It will not invent a percentage. If no rule in your rules table covers what you asked, it asks you rather than picking a number.

  4. Nothing sends without you

    Approve, and it writes a draft reply. A person still has to open that draft and press send. The app has no permission to send email at all — that is enforced by Microsoft, not by a setting I could get wrong.

If something goes wrong

Nothing here can break anything. The worst case is that it does not start, and you delete the folder and try again.

"The app is in a network folder"

You extracted it to the Desktop or Documents, and at work those live on the office server rather than on this PC. Drag the whole folder to C:\EDMZone\Quoting and run START-HERE-Setup.bat again. Nothing is lost — starting over is always safe.

"Python was not found" or the setup stops at step 1

The Add python.exe to PATH box was not ticked. Re-run the Python installer, choose Modify, and tick it. Or uninstall Python and install again, ticking it this time.

A wall of red text about "execution policy" or "not digitally signed"

You ran Setup.ps1 directly. Run START-HERE-Setup.bat instead — it exists precisely to get round this.

Sign-in fails mentioning "unauthorized_client" or "public client"

Allow public client flows in Stage B step 4 is still off, or Save was not clicked. Go back and check.

The check is green but no emails appear

Almost always the tag. Check it is exactly RFQ, that it is on the sales mailbox rather than your own, and that at least one email actually carries it. The connection check lists every tag it can see in that mailbox — compare that list against what you expect.

The browser says it cannot reach localhost:8000

The app is not running. Check the black window is still open. If it closed with a message, send it to me.

Anything else

Send me the text from the black window — all of it, not a summary. These messages are written to say which of the several possible causes it is, and that detail is the useful part.
