Seeing the app

A shareable preview builds from the repository itself. cd frontend && npm run build:demo writes dist-demo/preview.html — one self-contained file, no server needed, that opens straight from disk and shows the real workspace with recorded data in it.

It is a preview, not the system: nothing you click changes anything, and two people opening it do not share state. For staff to actually work in it, the backend has to be hosted and sign-in switched on — section J of the worklist covers what that needs.

Making this page render on GitHub

GitHub shows .html files as source code, not as pages. Turning on GitHub Pages fixes that and gives every document here a permanent web address:

  1. Repository Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: the current default, folder: /docs

After that this index lives at https://roger-edm-zone.github.io/Automated-Quoting-Machine/ and the worklist one click from it — versioned with the code, and updating whenever a change is pushed.

Note that Pages sites are public by default. If these documents should stay private, leave Pages off and open the files locally instead — the content is in the repository either way.
